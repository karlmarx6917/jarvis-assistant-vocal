# Jarvis - Assistant vocal local

Assistant vocal 100% gratuit pour Windows, écrit en Python.
Détecte le mot d'activation "Jarvis" et exécute des commandes vocales :
ouvrir des applications (Chrome, Steam, Discord...), éteindre/verrouiller le PC, etc.

## Technologies utilisées
- Python
- SpeechRecognition (Google Web Speech API)
- PyAudio

## Installation
pip install -r requirements.txt
python jarvis.py
